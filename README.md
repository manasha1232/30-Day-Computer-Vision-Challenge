## ⚡ Quickstart

1. **Clone the repository:**
   ```bash
   git clone https://github.com/manasha1232/30-Day-Computer-Vision-Challenge.git
   cd 30-Day-Computer-Vision-Challenge
   ```

2. **Install requirements:**
   ```bash
   pip install -r requirements.txt
   ```
